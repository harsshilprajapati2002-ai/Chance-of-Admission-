# 🎓 Chance of Admission for Higher Studies

## 📌 Overview

The **Chance of Admission for Higher Studies** project uses Data Science and Machine Learning techniques to predict the probability of a student getting admitted into higher education institutions. It analyzes various academic and profile factors to provide accurate predictions.

---

## 🎯 Objective

* To build a predictive model that estimates admission chances
* To help students make informed decisions about university applications
* To analyze key factors affecting admission

---

## 📊 Features

* Data preprocessing and cleaning
* Exploratory Data Analysis (EDA)
* Feature selection and correlation analysis
* Machine Learning model building
* Prediction of admission probability

---

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* Matplotlib / Seaborn
* Scikit-learn
* Jupyter Notebook

---

## 📂 Dataset

The dataset contains student-related information such as:

* GRE Score
* TOEFL Score
* University Rating
* SOP (Statement of Purpose)
* LOR (Letter of Recommendation)
* CGPA
* Research Experience

---

## ⚙️ Working Process

1. Data Collection
2. Data Cleaning & Preprocessing
3. Exploratory Data Analysis
4. Model Training (Regression Algorithms)
5. Model Evaluation
6. Prediction of Admission Chances

---

## 📈 Output

The model predicts the **probability (0 to 1)** of a student getting admission based on input parameters.

---

## 🚀 Future Scope

* Add real-time university recommendation system
